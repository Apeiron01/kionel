MOTION SYSTEM

Movement is a system, not decoration.

One easing curve, four durations, one travel distance. Everything on the site draws from this table. Motion that cannot name its token does not ship.

Tokens
easecubic-bezier(.22,.68,.28,1)
press160ms
hover220ms

mask780ms
stagger80ms
travel18px in · 2px hover
Rules
01Nothing bounces, nothing overshoots. One curve, always decelerating.
02An element animates in once. Scrolling back up does not replay it.
03Numbers never count up. Financial figures appear at their value.
04Nothing moves that the user did not cause — scroll, pointer or click.
05prefers-reduced-motion removes every animation, not just the large ones.

Scroll choreography

The order is fixed. A section never skips a rung or runs two at the same moment.

01
Smooth scroll
Momentum damping only. No hijacking — the page still ends where the user let go.
Headline
02
Text reveal
Line-by-line mask, never letter-by-letter. Headlines stay readable while they arrive.
03
Staggered content
80 ms apart, capped at five items. Longer lists arrive as one block.
04
Pinned scrollytelling
The transfer diagram pins while the three steps advance beside it. Used once per page.
Request a pilot
05
Interactive hover
Lift 1 px, drop a hard shadow, sink 2 px on press. Tactile, not glowing.
06
Depth, sparingly
A shallow parallax on the module field only. No WebGL scene the page cannot run without.

Heavy GPU work is deliberately out of scope. A security product that needs a shader to feel credible has the wrong argument — and a scene that stalls on a factory-floor tablet costs more trust than it buys.
