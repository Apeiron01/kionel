Vom Offline-Messrechner ins LIMS

Das LIMS ist im Netz. Der Messrechner absichtlich nicht. Dazwischen muss eine Ergebnisdatei hinüber, und wie sie hinüberkommt, entscheidet, ob das LIMS die Daten des Geräts enthält oder eine Kopie, die jemand angefertigt hat.

Von Taha Bayar, Biologe, der an der Datenübergabe zwischen isolierten Systemen arbeitet.

Die üblichen Wege

WegWas im LIMS ankommtWas er kostet
Ergebnisse abtippenWerte, nicht die DateiÜbertragungsfehler und eine zweite Person, die jeden Eintrag prüft.

So läuft es mit Kionel

  1. Auf dem Messrechner läuft das Offline-Paket: eine einzige HTML-Datei mit veröffentlichtem SHA-256, ohne Netz. Es zeigt die Datei als verschlüsselte Codes oder sendet sie über das Kabel und signiert einen Versanddatensatz mit SHA-256 und Auftragsnummer.
  2. Ein vernetzter PC in Chrome oder Edge empfängt. Unter Receive einmal Save received files to a folder wählen und den Ordner angeben, aus dem Ihr LIMS bereits importiert.
  3. Bei der Zustellung landet die Datei in diesem Ordner, daneben <name>.makbuz.json: die von beiden Rechnern signierte Bestätigung. Nichts wird überschrieben; eine zweite Kopie heißt name (2).csv.
  4. Ordnet Ihr Import Dateien nach Namen zu, setzen Sie File names in the folder, etwa {workorder}_{name}. Die Werte stammen aus dem signierten Datensatz; niemand benennt von Hand um.

Für Dateien, die laufend entstehen, kann der Messrechner einen Ordner überwachen und jede neue Datei unbeaufsichtigt über das Kabel senden; der Empfänger hört weiter und legt jede Datei mit Bestätigung ab. Kionel hat keinen LIMS-Konnektor und braucht keinen: Der Ordner ist die Schnittstelle.

Drei Hinweise für die Einrichtung des Imports

  • Warten, bis die Datei vollständig ist. Chrome legt die Datei zuerst leer an, schreibt in eine temporäre .crswap-Datei und tauscht erst am Ende. Den Import *.crswap ignorieren und warten lassen, bis eine Datei nicht leer und stabil ist.
  • Bestätigungen neben den Daten. Liest der Parser jede Datei im Ordner, *.makbuz.json ausschließen oder als Transfernachweis an die Probe hängen.
  • Berechtigung nach einem Neustart. Nach einem Browser-Neustart fragt Chrome einmal erneut nach dem Ordner; bis dahin werden Dateien nur zum Herunterladen angeboten, und die Anwendung sagt das.

Was das Audit sieht

Für jede Datei: den auf dem Messrechner signierten Versanddatensatz, die auf dem Empfangsrechner signierte Bestätigung, beide mit demselben SHA-256 und derselben Auftragsnummer, und eine Datei im LIMS-Ordner mit passendem SHA-256. Wie das zu den Anforderungen von EU-GMP Annex 11 passt, steht dort.
