Fünf Gründe für abweichende Hashwerte

  1. Jemand hat die Datei geöffnet und gespeichert. Excel schreibt eine CSV beim Speichern neu. Ob das passiert ist, zeigt die Excel-Prüfung.
  2. Zeilenenden wurden umgewandelt (Windows zwei Zeichen, Linux und macOS eines), etwa durch FTP im ASCII-Modus oder Git mit autocrlf.
  3. Die Kodierung hat sich geändert: UTF-8 als alte Codepage gespeichert ändert die Bytes von ä, ö, ü, µ.
  4. Es wurde eine andere Datei gehasht: gleicher Name, anderer Ordner, „(1)“ im Download, abgebrochene Kopie. Größe vergleichen.
  5. Ein anderer Algorithmus: SHA-1 hat 40, MD5 32, SHA-256 64 Zeichen.
