A saved profile keeps the expected source header, target names and checks together. Loading another file never silently replaces its rules.

Use one or several key columns, such as sample + test. Rule: ID width, decimal separator (. or ,), or allowed choices separated by |. Every mapped value is required. No rounding, trimming or unit conversion is performed.
