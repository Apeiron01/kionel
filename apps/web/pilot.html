OPEN SOURCE

Kionel is free and open source.

Every feature is included for personal and organisational use: signed dispatch and delivery records, reports, the local audit chain, the fast recording mode, printed pages, the one-way serial cable, receiver cards and site policies. Nothing to buy, no licence file to load.

Commercial licence and support

Kionel is developed by Taha Bayar at Lumina Digitale. If you want to build Kionel into a product without publishing your source, need help fitting it to an instrument workflow, or want a supported continuous serial link, write to us with a short description of the workflow. We answer by email.

What stays true

  • File content never reaches our server; the transfer happens between your two devices.
  • Records you already have stay verifiable forever with the Apache-2.0 verifier, with or without us.
  • Kionel has not had an independent security audit yet. The security page lists the current status and the limits page what it does not do.
