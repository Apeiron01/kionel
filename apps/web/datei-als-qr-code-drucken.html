Eine Datei als QR-Codes drucken und zurücklesen

Manche Rechner haben einen Drucker und sonst nichts: kein Netz, kein USB, keine Kamera. Kionel druckt eine Datei als Seiten mit verschlüsselten QR-Codes; jedes Handy mit Browser liest die Seiten in beliebiger Reihenfolge und baut die Datei Byte für Byte wieder auf.

Von Taha Bayar, Biologe, der an der Datenübergabe zwischen isolierten Systemen arbeitet.

Drucken

  1. Kionel auf dem Rechner mit Drucker öffnen (das Offline-Paket läuft ohne Netz), Print on paper wählen, Datei wählen, Dichte wählen und Print the file as codes drücken.
  2. Kionel zeigt einen 12-stelligen Code in großer Schrift. Notieren und getrennt von den Seiten aufbewahren: Ohne ihn sind die Seiten nicht lesbar.

Zurücklesen

  1. Auf dem Handy Kionel öffnen, Receive → Printed pages, Code eingeben. Man kann auch zuerst scannen: Sind alle nötigen Codes gelesen, fragt Kionel nach dem Code, und ein falscher Code verwirft nichts.
  2. Kamera auf die Seiten richten, eine nach der anderen, in beliebiger Reihenfolge.

Text und CSV werden vorher komprimiert. Kionel druckt und liest bis zu 60 Seiten und öffnet auch Fotos und Scans der Seiten.

Wenn ein Code verschmiert oder eine Seite eingerissen ist

Etwa 30 % der Codes sind Reserve. Sie sind keine Kopien: Jeder mischt ein Drittel der Datei und kann für jeden verlorenen Code einspringen. In unseren Tests kam eine 30-KB-Datei mit 8 von 48 fehlenden Codes in 91 % von 300 Versuchen zurück, eine 150-KB-Datei mit 12 fehlenden Codes in allen 100 Versuchen. Mit gewöhnlichen zufälligen Reservecodes waren es bei der 30-KB-Datei 3 %.
