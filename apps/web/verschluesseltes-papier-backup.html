Ein verschlüsseltes Papier-Backup Ihres Tresors, Ihrer Codes oder Schlüssel

Ein Papier-Backup übersteht eine defekte Festplatte, ein verlorenes Handy und ein gesperrtes Konto. Der übliche Rat, den Export als Text zu drucken, legt jedes Passwort auf ein Blatt, das jeder lesen kann. Kionel druckt die Datei stattdessen als verschlüsselte QR-Codes.

Von Taha Bayar, Biologe, der an der Datenübergabe zwischen isolierten Systemen arbeitet.

So geht es

  1. Datei exportieren. In Bitwarden: Tools → Export vault; am stärksten ist .json (Encrypted) mit Password protected, das braucht aber mehr Seiten, weil verschlüsselte Daten sich nicht komprimieren lassen. In KeePassXC die .kdbx-Datenbank selbst drucken: Sie ist bereits verschlüsselt. 2FA-Codes als Textdatei speichern.
  2. Mit Kionel drucken: Kionel öffnen, Datei wählen, Print on paper, bei Bedarf Dicht wählen.
  3. Code getrennt von den Seiten aufbewahren. Ohne den 12-stelligen Code sind die Seiten nicht lesbar.
  4. Den unverschlüsselten Export löschen, auch aus Downloads und Papierkorb.
  5. Die Wiederherstellung einmal testen: Handy, Receive → Printed pages, Code eingeben, Kamera auf die Seiten.

Warum zwei Schichten Verschlüsselung

Der Code schützt die Seiten mit einem Schlüssel aus 12 Zeichen (60 Bit); jeder Rateversuch kostet 600.000 PBKDF2-Runden. Das hält jemanden auf, der den Umschlag findet. Für Geheimnisse, die jahrzehntelang gegen einen gut ausgestatteten Angreifer halten sollen, einen bereits passwortgeschützten Export drucken: Das Papier enthält dann eine doppelt verschlüsselte Datei.

Was der Drucker sieht

Nur die verschlüsselten Codes. Büro- und Netzwerkdrucker speichern Aufträge oft; mit Kionel ist diese Kopie genauso unlesbar wie das Papier, solange Sie den Code nicht mitdrucken.
